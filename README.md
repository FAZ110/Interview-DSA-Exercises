Welcome to my **Data Structures and Algorithms (DSA)** repository! 

This repository serves as a personal archive of my solutions to popular algorithmic problems, primarily from NeetCode and LeetCode. It is designed to track my progress, solidify my understanding of core computer science concepts, and prepare for technical software engineering interviews in the future.

---

## 🧠 What's Inside?

This repository contains optimized solutions to various DSA problems, categorized by their primary data structure or algorithmic paradigm. Where applicable, I include:
* **Problems descriptions** at the top of every file.
* **Optimized solutions** for every problem.
* **Solution ideas** every file has either Main Idea text before the code to describe the solution or comments beside code.

### 🗂️ Directory Structure

Solutions are organized by topic to make navigation easy.
